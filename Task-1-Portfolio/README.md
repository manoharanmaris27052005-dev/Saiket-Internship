# Task 1 - Static Portfolio Website

## Project Overview

A responsive and professional personal portfolio website developed as part of the SaiKet Systems Full Stack Development Internship.

The portfolio showcases my profile, technical skills, projects, education, experience, and contact information.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Features

- Responsive navigation bar
- Professional hero section
- About Me section
- Education and experience
- Technical skills section
- Projects section
- Contact form
- JavaScript form validation
- Resume view and download
- GitHub and LinkedIn links
- Smooth section navigation
- Responsive design for mobile and desktop
- Professional theme and UI animations

## How to Run

1. Clone or download the project.
2. Open the `Task-1-Portfolio` folder in VS Code.
3. Open `index.html`.
4. Run the project using Live Server or open `index.html` in a browser.
